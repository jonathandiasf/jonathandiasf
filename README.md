## 🚀 About me

Sou estudante de **Engenharia de Software** e desenvolvedor Full-Stack, interessado em transformar problemas reais em soluções digitais bem estruturadas.

Minha principal stack combina **Python, Django, React e PostgreSQL**, com experiência prática em desenvolvimento de aplicações web, APIs REST, modelagem de dados e organização de projetos.

Gosto de compreender o software além do código: como os componentes se comunicam, como os dados são organizados, como a aplicação pode escalar e como a segurança deve fazer parte do desenvolvimento desde o início.

Atualmente, direciono meus estudos para:

- 🏛️ Arquitetura de Software e Sistemas.
- 🔐 DevSecOps e segurança de aplicações.
- 🐳 Containers, Docker e automação.
- 🧠 Inteligência Artificial aplicada ao desenvolvimento.
- 🧪 Testes automatizados e qualidade de software.
